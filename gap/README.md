# THE GAP

사주 · 별자리 · MBTI · 심리테스트 — 서로 무관한 네 개의 성격 이론에 같은 사람을 넣고,
「타고난 나」와 「내가 아는 나」가 얼마나 떨어져 있는지 재는 진단 테스트.

결과 순서: 유형 이름 → **당신이 말하지 않은 것 4장** → 격차 점수 → 이야기 →
다섯 장면 → 답변 속의 모순 → 네 심판 → (접힘) 계산 과정.

## 「당신이 말하지 않은 것」 — 11문항과 무관하게 생년월일시만으로 산출
| 카드 | 근거 | 종류 |
|---|---|---|
| 처음 본 사람의 눈 | 상승궁 | 12 |
| 안에 없는 것 / 넘치는 것 | 오행 최소·최대 | 11 |
| 갈라진 시점 | 대운 전환 나이 | 연속값 |
| 혼자 있을 때의 당신 | 달자리 | 12 |

대운은 양남·음녀 순행 규칙으로 순역을 정하고, 생일에서 절입까지의 일수를 3으로 나눠
대운수를 구합니다. 성별 입력이 필요한 이유입니다.

「답변 속의 모순」은 사주가 아니라 사용자가 고른 11문항의 축 값끼리 충돌하는 지점을
탐지합니다(규칙 16 + 축별 예비 문장 10). 유형 11종.

## 구조
- `index.html` — 화면, 문항, 결과 렌더링
- `engine.js` — 만세력·천문 계산 및 5축 좌표 변환

빌드 도구 없음. 두 파일을 그대로 올리면 동작합니다.

## 5축
발산·수렴 / 추진·지속 / 논리·정서 / 구체·관념 / 자기·관계

| 축 | 사주 | 별자리 | MBTI |
|---|---|---|---|
| 발산·수렴 | 천간지지 음양 비율 | 원소(화·풍 / 토·수) | E–I |
| 추진·지속 | 생지·왕지·고지 | 활동·고정·변통궁 | P–J |
| 논리·정서 | 오행(금수토 / 화목) | 원소(풍토 / 수화) | T–F |
| 구체·관념 | 오행(토금 / 수목화) | 원소(토 / 풍화) | S–N |
| 자기·관계 | 십신(비겁식상 / 재관인) | 1~6궁 / 7~12궁 | 약한 근사 |

축마다 서로 다른 재료를 쓰기 때문에 축 간 상관이 낮습니다.

## 계산 정확도
- 년·월주: 태양황경(절기) 기준, 오차 ~0.01°
- 일주: 율리우스일 기준 (1900-01-01 = 甲戌 앵커)
- 시주: 서울 진태양시 32분 보정
- 달 황경 오차 ~0.3°, 상승궁은 서울 좌표(37.57N / 126.98E) 고정
